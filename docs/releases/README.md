# Releases

Per-version release notes, one file per tag.

## Version numbers

**MINOR marks a rollout-phase change** (spec §10: shadow → sandbox → live-min-size
→ scale). `v0.3.0` was the sandbox live-fire flip — `dry_run_submissions = false`,
2026-08-13 — and CLAUDE.md dates that phase by the version number, which is the
property worth protecting. The next MINOR is the live-min-size flip.

**In practice the MINOR has also marked a phase of WORK, twice, and each was a
deliberate call by Richard.** `v0.4.0` (2026-09-10) marked go-live preparation, and
`v0.5.0` (2026-09-23) marks **optimizing the current strategy** (not scaling it): until then Argus only *defended*
a position (a stop, a clock) and from `v0.5.0` it also *harvests* one (the profit
target, and a ledger that values a trade held to expiry). **Neither changed the
rollout phase** — Argus is still live at minimum size, and the size rails are
untouched. Read the MINOR as "Argus manages the same strategy better", not "the size
went up"; the scale phase is a separate, later call.

**PATCH is everything else** — fixes, new tools, docs, config retunes. A new
read-only tool is a PATCH here even though strict semver would call it a MINOR:
the version tracks the ROLLOUT, not the codebase, and spending a MINOR on
something that changes no rail would cost the number its meaning.

Orthogonal to both: **a `src/` change needs an image rebuild, a config-only one
does not.** Each release's notes say which it is at the top. That distinction is
about deployment, never about the version number — `v0.3.0` was config-only and
`v0.3.1` was a rebuild, and they are adjacent.

## Release names — Argus's Eyes

Argus Panoptes was covered in a hundred eyes, and the myth's whole point is that
they could never all be closed at once: something was always watching. So releases
are named after **real stars whose names read as "the eye"** across astronomical
traditions. On-brand twice over — eyes for the watchman, stars for a system that
spends all day reading a sky — and it gives a finite, real pool to draw from
rather than something to invent fresh each time.

**The rule is loose about etymology on purpose.** Some names are literally "eye"
(Ain, from Arabic ʿayn); others earn it by position or tradition (Aldebaran is
etymologically "the follower", but it is universally the Bull's Eye). Either
qualifies. What does not qualify is a star picked only because it sounds good.

**Pick the name for the shape of the release**, not in sequence. Algol — the one
star ancient observers watched visibly dim and return on a clock — went to the
release that fixed an eye which had been blinking. That fit is the point.
