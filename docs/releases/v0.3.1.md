# v0.3.1 — Algol

*β Persei, "the Demon's Eye" — the eclipsing binary ancient observers watched dim
and return on a clock. This release fixed an eye that blinked.*

Fixes from the first live-fire sandbox session (2026-08-13). Requires an image
rebuild — this is a `src/` release, not a config-only one like v0.3.0. Deploy the
config together with the image: `argus.toml` now assumes the code below.

## Fixed

**Concurrency limit was counting legs, not spreads.** `max_concurrent_positions`
compared against the broker's leg count, so a limit of `2` permitted exactly one
vertical (402 of 404 gate decisions on 2026-08-13 denied `concurrent_limit`). The
gate now reads a broker-derived spread count (`ceil(legs / 2)`), still refusing to
trust the ledger alone. `max_concurrent_positions` is set to `2` (real spreads) for
cert/sandbox, with `daily_max_loss` raised 1740 → 2500 to keep
`concurrent × per-position ≤ daily` exact. Sandbox still can't enforce that budget
— day P&L is structurally zero there — so this is unvalidated until live.

**A stale leg quote blinded the underlying stop-loss backstop.** On a stale or
missing quote, the watchdog discarded the leg's strike along with its price,
so the backstop trigger — the one designed to keep working when the option
market can't be priced — went unevaluable too. Confirmed live: a position sat
fully unwatched in the closing minute of expiry. Leg identity and leg price are
now resolved independently; a stale quote only costs the credit trigger.
`/status` now surfaces per-leg staleness for open positions.

**Book-disagreement alerts paged on every single entry.** Argus's ledger books
a fill before the broker's own position book catches up (observed 4–5s lag),
which tripped an ERROR-level page each time. Added a 20s settle allowance on
that direction only — a real held-but-unwatched position still pages instantly.

**Live-fire days produced no P&L record.** The shadow marker only scored
`shadow.would_submit` / `entry.dry_run` proposals held to settlement; a live
position closed intraday by the watchdog wrote neither and settlement scoring
doesn't apply to it anyway. Outcomes are now built from actual fill prices for
positions closed before expiry, alongside the existing settlement path for
anything held to the close.

**Repeated "position unevaluable" alerts during ordinary quote gaps.** A
one-trigger-down, one-trigger-live position (the common case once the backstop
fix above landed) now pages once and stays Tier 2 while it persists, instead of
alerting on every occurrence. A new tool, `argus.tools.evaluability`, reports
the blind/degraded episode counts and audit write rate per session — that's how
the next tuning pass on this gets measured instead of guessed.

## Also
