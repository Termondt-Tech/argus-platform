# Argus designs — proposals awaiting sign-off

Design documents written **before** implementation, for changes where the
implementation *shape* is the open question rather than the problem.

This directory is **not normative**, and that is the whole reason it is separate
from `docs/decisions/`. A file here is a proposal: it records what was read, what
was measured, which shapes were considered, and which one is recommended — and it
is live until Richard signs off or overrules it.

The lifecycle:

1. A task prompt lands in `docs/tasks/`.
2. If it says "design first", a proposal lands here.
3. On sign-off, the implementation ships and a **decision record** lands in
   `docs/decisions/` — normative, past tense, carrying the measurement and the
   reasoning that must outlive the diff. Add its row to
   [`docs/decisions/README.md`](../decisions/README.md).
4. The proposal here stays, marked with its outcome, as the record of what was
   *rejected* and why. That is the half a decision record tends to lose.
