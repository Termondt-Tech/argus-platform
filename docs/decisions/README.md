# Argus decision records

Settled design decisions and closed investigations, one file per topic. These
were relocated out of `CLAUDE.md` on 2026-08-12 — that file is loaded into every
Claude Code session regardless of task, so narrative that documents *how a past
problem was solved* belongs here, while `CLAUDE.md` keeps only what is needed to
work on the repo today.

**Everything here is normative.** "Do not relitigate" means what it says: these
record decisions that were made deliberately, usually with a measurement or an
incident behind them. Read the relevant file before changing the component it
covers.

Design *rationale* lives here; `docs/0dte_spx_desk_spec.md` holds the spec, and
`docs/architecture/` holds the C4/UML shape of the system.
